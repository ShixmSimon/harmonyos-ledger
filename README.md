# 本地记账

一个面向个人使用的 HarmonyOS 记账应用，最低目标为 HarmonyOS 7 / API 26。项目使用 ArkTS、ArkUI 和本地 ArkData，不提供账号或云同步。

## 主要功能

- **账目管理与统计**：记录、编辑和删除收入与支出；按记账周期或自选日期范围查看收支、结余、趋势及分类、商户和来源统计。
- **截图 OCR 导入**：识别微信支付、支付宝和工商银行账单截图，也支持从其他应用分享截图。识别规则可编辑；解析结果先作为草稿供用户复核，确认后才保存。
- **通知自动记账**：用户授权通知访问后，应用按可编辑规则处理通知。初始规则覆盖工商银行、中信银行、支付宝和微信支付；只有匹配规则且能识别有效金额、收支方向和时间的通知才会记账。通知内容可在设备本地归档。
- **CSV 备份与恢复**：导出全部账目，或导入本应用导出的 CSV。导入时会预览无效记录和与现有账目完全相同的记录，确认后再写入。

## 数据与隐私

账目、通知归档及 OCR/通知规则保存在设备本地，OCR 和通知处理也在本机完成。截图和导入的 CSV 只在当前流程中读取，不上传或长期保存。通知归档可能包含敏感内容；卸载应用可能删除本地数据，建议定期导出备份。
